# SauceDemo – Manual Testing Test Plan

## 1. Project Overview
This project covers manual testing of the SauceDemo e-commerce web application.
Application: https://www.saucedemo.com/

## 2. Test Objectives
- Verify the main application functionalities.
- Validate user login and shopping workflows.
- Identify and document application defects.
- Check input validations and error messages.
- Evaluate the overall user experience.

## 3. Scope of Testing

### In Scope
- Login and Logout
- Product Listing
- Product Sorting
- Shopping Cart
- Checkout Process
- Form Validation
- Order Confirmation

### Out of Scope
- Performance and load testing
- Security penetration testing
- Backend API testing
- Payment gateway integration testing

## 4. Testing Types
- Functional Testing
- Negative Testing
- Exploratory Testing
- Regression Testing
- User Interface Testing

## 5. Test Approach
Testing will be performed manually using defined test scenarios and test cases.
Actual results will be compared with expected results. Any reproducible defects will be documented with steps and supporting evidence.

## 6. Test Environment
- Application: SauceDemo
- Browser: To be recorded during execution
- Operating System: To be recorded during execution
- Testing Type: Manual Testing

## 7. Test Deliverables
- Test Plan
- Test Scenarios
- Test Cases
- Test Execution Results
- Defect Reports
- Test Summary Report

## 8. Entry Criteria
- Application is accessible.
- Test environment is available.
- Test scenarios are prepared.

## 9. Exit Criteria
- Planned test cases have been executed.
- Results have been documented.
- Identified defects have been reported.
- Test summary has been prepared.
