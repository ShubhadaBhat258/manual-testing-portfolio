# SauceDemo – Manual Testing Project

## Project Overview
This project focuses on manual testing of an e-commerce web application called SauceDemo.

Application: https://www.saucedemo.com/

## Project Objective
To verify application functionality, identify defects and evaluate the overall user experience.

## Testing Scope
1. Login and Logout
2. Product Listing and Sorting
3. Shopping Cart
4. Checkout Process
5. Input Validation

## Testing Types
- Functional Testing
- Negative Testing
- Exploratory Testing
- Regression Testing

## Testing Approach
Manual test cases will be designed and executed.
Actual results will be compared with expected results. 
Defects will be documented with reproduction steps and supporting evidence.
